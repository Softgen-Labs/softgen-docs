## Using Your Own Supabase (Advanced)

If you need to connect your own existing Supabase project instead of using the platform-managed option, you can do so through environment variables:

1. Go to your project **Settings**
2. Navigate to **Environment Variables**
3. Add your Supabase credentials:
   - `NEXT_PUBLIC_SUPABASE_URL`
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - `SUPABASE_SERVICE_ROLE_KEY` (for admin operations)

> **Note:** This approach requires manual configuration and is only recommended for advanced users who need to use a specific Supabase organization or have special requirements.

## What is Supabase?

Supabase is an open-source Firebase alternative that provides:
- **Database**: PostgreSQL with full SQL support
- **Authentication**: Multiple providers (email, Google, GitHub, etc.)
- **Storage**: File hosting and management
- **Real-time**: Live data updates across clients
- **Edge Functions**: Serverless TypeScript functions
- **API**: Auto-generated REST and GraphQL APIs

Everything you need for a modern full-stack application, integrated directly into Softgen.
